# AI and artwork acceptance audit

Reviewed against the [AI engine requirements](../../report/src/pages/ai-engine.html) and [artwork subtree requirements](../../report/src/pages/art-subtrees.html) on 18 November 2026.

**Verified** means the listed acceptance behavior was observed. **Partial** means only some required behavior is implemented or only a narrower acceptance case has been demonstrated. **Implemented but unverified** means the expected code path exists and the specified acceptance check has no recorded result. **Missing** means the requested path was not found. Earlier Codex protocol probes and browser replay are distinct from current native, live-provider and cross-platform acceptance. Unless named in a row, those environments and latency thresholds remain unverified.
