Other desktop mind mappers

Besides MindNode, a handful of established applications define what mind-mapping software does in late 2026. Xmind is the best-evidenced and the most relevant to Radiant, Ayoa is the only mainstream product built around an organic Buzan look, and the rest are either value options, open-source tools or different paradigms. This page profiles each one as far as the research verified, then extracts what Radiant should borrow or avoid.

Implication for Radiant

Xmind's per-branch structure switching is the closest shipping analogue to Radiant's per-subtree picture and SVG representations, and its command-line tool for coding agents shows how an app can expose a native file to Codex. Ayoa shows that the organic look has a market but its rendering is undocumented. The shared weakness of the incumbents is large-map responsiveness, which is where Radiant aims to differ. Pricing evidence from aggregator sites is unreliable and conflicts throughout.

Xmind

Xmind is a cross-platform mapper for Windows, macOS, Linux, iOS and Android, with a native .xmind file and an agent-facing command-line tool. It is the most relevant competitor to study for Radiant.

Structures and per-branch mixing

Xmind and its App Store listing name nine structures: Mind Map, Logic Chart, Brace Map, Org Chart, Fishbone, Timeline, Tree Chart, Tree Table and Matrix. Switching is one click, and several structures can be combined on the same map. Xmind guide App Store Tree Table is the newest, with topics in nested rectangles for comparison and multidimensional lists. Tree Table

Mixing happens per branch: "each branch can be a unique structure". The user selects a subtopic, opens the Format panel and chooses Structure. The main topic keeps its own structure and only that branch changes. The example mixes an org chart, a matrix and a logic chart in one map. The article is dated 27 July 2020, so the mechanism is long-standing. Combining structures

Idea for Radiant

Borrow Xmind's interaction pattern for the signature feature: select a branch, open a Format panel, choose a representation (normal, picture, SVG), and apply it to that branch only. The mapping from Xmind's structures to Radiant's representations is an inference.

Look and modes

The Xmind 2022 release brought a hand-drawn style, a Pitch panel with real-time preview, a Smart Color Theme, 30 templates, over 400 stickers and 40 illustrations. Hand-drawn is a one-click switch of the whole map's look. Xmind 2022 Xmind blog The notes infer that this is a filter applied to boxes and lines, not Tony Buzan's tapered curves, but the rendering was not seen. How Smart Color Theme works is not verified.

Pitch mode turns a map into a slide show with smooth transitions and generated layouts. Later additions include fishbone and timeline layouts, a "Thank You" page and rich-text notes in Pitch, none of them dated. ZEN mode is a full-screen view with the panels hidden, and a later release added Light, Dark, Ultra Light and Ultra Dark appearances in it. App Store The May 2026 newsletter lists AI image-to-editable-map and a "pitch video" with theme, duration and music. May 2026 newsletter The features page lists LaTeX equations, markers, labels, notes, attachments, custom colour themes and PDF and PNG export. Xmind features

Agents: the command-line tool and skill

The Xmind Skill and CLI, installed with npm install -g @xmindltd/xmind-cli followed by xmind setup skills and xmind auth login, lets Codex, Claude Code, Cursor and OpenCode create, read, edit and validate native local .xmind files. It requires signing in to an Xmind account. It cannot generate new images but can attach existing ones, and some options use credits. A separate Xmind MCP server works with cloud maps. Xmind CLI The pattern of an agent editing a native local file and validating it, with unrelated branches preserved, is the relevant lesson. The Premium tier gating of AI and credits is the model the Codex subscription design avoids (inferred).

Performance complaints and their age

All complaints found are old. A 920 MB Xmind 2020 or 2021 map with embedded images and documents took about 1 minute 40 seconds to open on macOS Big Sur. Xmind 8 Pro lagged on sheets with many branches, and saving was slow with many attachments. Xmind forum Xmind forum 2 A further anecdote in the notes mentions Xmind search lag of up to a minute on very large files, without a specific source. No 2025 or 2026 complaints were found, so the current state is unknown. An Xmind "2027" release appears in only one vendor-style listing and no independent source was found.

Ayoa and the iMindMap lineage

Ayoa is the only mainstream product positioned on an organic Buzan look. Most of the evidence is vendor marketing and should be read that way.

  • Lineage. iMindMap was developed by Chris Griffiths with Tony Buzan from 2005 to 2019. OpenGenius launched Ayoa in 2019 as its cloud successor, and Ayoa says iMindMap is replaced by Ayoa. Ayoa Whether an iMindMap desktop product is still available was not verified.
  • Organic branches. The vendor describes curved branches that taper from a thick centre to fine tips, can be bent by hand, and can be drawn freehand. It characterises MindMeister as "clean, tidy". This is a vendor claim. Ayoa comparison
  • Contradiction. A GetApp listing says the thickness of branches cannot be adjusted. GetApp The vendor says branches taper and bend, and the listing says thickness cannot be adjusted. These may refer to different things, such as automatic taper versus user control, but the notes do not resolve it.
  • Freehand. TechRadar says freehand drawing is retained from iMindMap and works on mobile or with a stylus. The article body could not be retrieved, so this is a search summary. TechRadar
  • Platforms and tiers. The vendor pricing page lists a free plan of 10 maps, a 7-day Ultimate trial, a web app and iPhone, iPad and Android apps, and no desktop app. Ultimate is billed per user monthly, annually or every three years, and no prices are listed. AI mind mapping, idea generation, analysis and summaries are Ultimate-only. Ayoa pricing A competitor blog cites $13 per user per month billed annually, which is unverified, and an earlier pass found about $10. MindMap AI blog
  • AI and images. "AI Prompt to Mind Map" and "Generate Ideas" exist. AI image generation is documented for the mobile app. A node image can be added by upload or by a royalty-free web search. Ayoa AI prompt Ayoa AI images
  • Modes. The vendor site names organic, radial and "Smartsway" views, and the pricing page lists "multiple modes" without naming them. Smartsway
Not verified

No source describes how Ayoa or iMindMap renders organic branches, and no source confirms that text follows the branch curve. The notes infer a plausible method: each branch is a cubic Bezier curve with a width profile, drawn as one filled outline, similar to the taper output of the perfect-freehand library. That is an inference about how one could build it, not a description of Ayoa. Speed-map mode, image-as-node, how an image attaches to a branch and performance with images were not found either.

The rest

iThoughts

End of trading

toketaWare announced on 30 January 2024 that it had ceased trading. There are no more updates. Existing installs run until an operating system change breaks them. Setapp installs ended after 2 February 2024. The status of the non-X iThoughts was not stated. MPU forum MindNode can still import iThoughts files.

Windows and Mac

Aggregators give about $349 one-time or $99 to $169 per year, which is unreliable. No AI features are confirmed, and the Mac app reportedly gets mostly maintenance. GPL-3.0, GTK

Keyboard conventions

Tab for a child and Enter or Return for a sibling is the de facto standard across MindNode, Xmind, SimpleMind, Whimsical, Visio and MindMup (the last depending on orientation). Freeplane differs, and Miro reportedly reverses Enter and Tab. Taskade uses Tab for indenting, and a feature request asks for Tab as child. Taskade forum "Not listed" in the table means the retrieved page omitted the action, not that the tool lacks it.

File formats worth supporting

The widely supported interchange formats are OPML, FreeMind .mm, Markdown and Xmind. MindNode imports FreeMind, iThoughts, OPML, XMind and Markdown, and exports FreeMind, OPML, Markdown, SVG, PDF and PNG. MindNode import and export Minder imports OPML, FreeMind, Freeplane, Markdown, Mermaid and XMind. Minder Coggle exports .mm, and Xmind Pro exports Markdown, SVG, PDF and Office formats.

The notes' suggested priority, which is an inference, is: Radiant's own format first, then OPML, FreeMind .mm, a Markdown outline, SVG, PNG and PDF export, and Xmind import last. Open plain-text or JSON formats (the notes cite JSON Canvas, Markdown outlines and the .excalidraw format) are what make agent integration easy, so a documented JSON map file would itself be Radiant's agent interface. The notes also recommend storing images as external assets with thumbnails and mip levels rather than embedded blobs. Both are inferences.

What this means for Radiant

  • Design the representation switch like Xmind's structure switch. A Format panel action that applies to the selected branch only is a familiar pattern, and it already shipped in Xmind years ago.
  • Do not rely on a global hand-drawn filter for the organic look. Tapered curved branches need their own geometry. Treat perfect-freehand and rough.js as references, not as drop-in solutions.
  • Make large-map responsiveness a visible advantage. MindManager and Xmind have reports of slowness on large files with embedded media, though the Xmind reports are old. The notes infer that a GPU-accelerated design with level of detail and rasterised subtrees fits this gap.
  • Use an open, documented file. It supports both interchange and agent access. Offer OPML, FreeMind and Markdown first.
  • Follow the keyboard convention. Tab for child and Return for sibling, plus Shift+Return for sibling before, are the safest defaults. Leave parent, fold, note and link configurable because no standard exists.
  • Expect no price anchor from this page. Vendor prices found are Xmind at $4.92 and $8.25 per month and Ayoa unlisted. All other figures are aggregator quotes with conflicts.
