MindNode, feature by feature

MindNode is the app the reader uses today, so it is the baseline for Radiant. This page inventories what MindNode does as of November 2026, explains how each feature behaves where the documentation says, and gives a verdict on every feature: adopt as is, adapt, or skip. The verdicts are judged against Radiant's goals of speed on large maps, AI generation through Codex, picture and SVG subtrees, and memorability.

Implication for Radiant

Most of MindNode's core interaction model should be copied closely: the Tab and Return keyboard model, an auto layout with relative-offset manual moves, folding, a synced outline, cross connections and themes. The main departures are to make layout incremental for large maps, to generalise stickers into image and SVG subtrees, to replace iCloud sync with an open file format, and to use MindNode's read-only-by-default agent pattern for the Codex integration.

MindNode in 2026

MindNode today is a rebuilt app named "MindNode: Mind Map & Outline" in the App Store. It was previously called MindNode Next and, according to the developer, will be called simply MindNode. It runs on Mac, iPhone, iPad, Vision Pro and Apple Watch, and has no Windows, Linux or web version. MindNode site

AI and agents

Documented

On-device Apple Intelligence provides brainstorming, text generation and image background removal. An MCP server (Model Context Protocol, a standard way for AI assistants to call an app's tools) exists on the Mac only. Assistants are read-only by default and write access must be granted. It works with Claude Desktop, Claude Code, ChatGPT for Mac, Codex and Mistral Vibe. AI can be turned off in Settings. MindNode 2026.5

The Classic and rebuilt app situation

MindNode Classic still exists and is included with any Plus subscription. The rebuilt app is built on a new foundation for conflict-free sync and collaboration. It does not sync with Classic because the architecture is very different, although files can be imported in both directions with some loss of features. Documents in the rebuilt app are managed inside the app through iCloud and are not visible files. Next guide

Feature parity between Classic and the rebuilt app is published only as a roadmap drawn as an SVG mind map, which the research could not read as text. Which Classic features are still missing in November 2026 is therefore unverified. Parity roadmap At the rebuilt app's launch, around December 2024, manual layout and many exporters were missing, the developer called manual layout a priority, and Quick Entry was reported missing. Direction of the product

The notes infer that MindNode in 2026 is Apple-native, collaborative (the conflict-free wording suggests CRDT-style sync, which is inferred) and AI-assistive rather than AI-generative-first. An app that takes a topic and a requested style and has Codex produce the whole map is therefore differentiated from MindNode's Apple Intelligence brainstorming. The absence of any Windows, Linux or web app also leaves an open lane for a cross-platform, fast desktop app. Both points are inferences, not statements from MindNode.

MindNode also retired its web publishing service, myMindNode. New uploads stopped in September 2024, the service ended on 28 March 2025 and data was deleted on 15 April 2025. The shutdown notice says it never found a large audience and that SVG export is the suggested web alternative. Shutdown notice

Canvas and nodes

MindNode's canvas holds one or more main nodes per document, each with its own tree of children. New main nodes are added with Shift+Return. Manual moves as offsets

The rebuilt app has no separate manual mode. Any node can be dragged and then keeps its position relative to its parent. While dragging, a shadow shows where the node will snap back to, and dragging far enough shows an indicator that the node will stay at an offset. Holding Option overrides the behaviour. The Organize menu offers Balance, Move All Nodes and Reset Position. Styling guide

The notes infer that the app stores a delta from the automatic layout position, so the automatic layout stays authoritative and manual tweaks survive a reflow. The notes also infer, without documentation, that overlap avoidance is a layout pass that sizes subtrees and spaces siblings, with manual offsets applied afterwards. Both are inferred.

Outline, focus and capture

Outline

The outline is always in sync with the map. Main nodes appear in creation order. First-level children follow clockwise map order, and deeper levels run top to bottom. Font size and colour are ignored in the outline, while bold and italic are kept. Return splits a node in the middle of its text and Backspace merges nodes. Dragging a line left or right changes its hierarchy level. Tasks appear on the right, and options show tags and content indicators. Outlining guide A side-by-side map and outline view arrived on 21 October 2026. MindNode releases Outline editing is a Plus feature. App Store

Folding

Holding Option while hovering a node shows a fold arrow, and an indicator on a folded node unfolds it. There is an action to unfold one level, and nested folders arrived in 2026.3. Folding guide

Focus Mode, visual tags and capture

Focus Mode (Shift+Cmd+F) and Visual Tags are listed as Plus features. MindNode pricing Their behaviour is not described in the documentation pages the research retrieved. Quick Entry, a menu-bar capture feature, is recalled from background knowledge about Classic and was reported missing from the rebuilt app at launch. "Wells", a further MindNode term that came up during the research, does not appear in any page the research fetched.

Styling and themes

Themes are the best-documented styling feature. Personal themes extract the canvas colour, main node style, child node style, branch style, branch colouring of first-level nodes, connection style and fonts from an existing document. MindNode recommends a sample with one main node, six children and one connection. There are also hierarchical themes, and dynamic themes that follow the system light and dark mode. Themes guide Release 2026.3 gave free users extra styling and layout controls, a basic sticker set and an "Important" tag, although the pricing page still lists many of these under Plus, so the exact free and paid split is unclear. MindNode 2026.3

Style copy and paste is available with Option+Cmd+C and Option+Cmd+V. Shortcuts Typography options, tag colours and the size of the sticker library are not documented in the fetched pages.

Tasks, tags and connections

Cross connections

A connection is created with Cmd+L and a click on the target, or by Shift+dragging. A draggable middle waypoint curves the line and a double-click straightens it. A double-click on the connection adds a title. Connections guide

Tasks

A node can carry a checkbox. A parent node then shows a progress indicator with a percentage on hover, and clicking the parent's indicator completes all subtasks. Reminders sync is two-way for completion, but creation goes one way only: tasks made in MindNode appear in Reminders, while tasks made in Reminders do not appear in MindNode. The Reminders list is named after the document, and each reminder includes the notes, tags, path and a deep link. Export to Things and OmniFocus is one-way. The page does not mention due dates. Tasks guide

What this means for Radiant

  • Copy the keyboard model completely. MindNode's Tab and Return conventions match the rest of the market, so a user moving from MindNode keeps their habits.
  • Store manual moves as offsets from the automatic position. This lets automatic layout stay authoritative. Radiant should add incremental layout so that editing one node does not re-lay out a large map.
  • Choose layout and representation per subtree. MindNode already allows layout per main node. Radiant extends the same idea to a raster or SVG representation for any subtree.
  • Treat the outline as the AI interface. A synced outline gives Codex a plain-text format to read and write. See the AI engine.
  • Own an open file format. MindNode hides its documents inside iCloud, which is a known complaint. The notes infer that a JSON file plus an assets folder is a good choice, with OPML, FreeMind .mm, Markdown and SVG or PNG export first. See the feature list.
  • Make agent access read-only by default. MindNode's MCP server asks the user to grant write access, and its history marks AI changes. Both are good patterns for Codex.
  • Do not rely on MindNode's documentation for everything. Several features still need a hands-on check in the app the reader already has, as listed below.
